About This Website

The three pages are connected with normal HTML hyperlinks. The first page is the welcome page, the second introduces the two main-event fighters, and the third contains event details and the fight card.

Internal linking example: Go directly to the HTML/CSS topics used below.

HTML5 and CSS3 Topics Used

CSS text flow:
This note floats beside the text on wider screens and becomes a normal block on smaller screens.

This project intentionally uses basic elements instead of a framework. It uses semantic page structure, headings, paragraphs, links, images, lists, tables, forms, input types, a datalist, autocomplete, and meta elements.

HTML5 elements demonstrated

  • Semantic elements: header, nav, main, section, article, aside, footer
  • Lists: unordered and ordered lists
  • Images and internal links
  • Tables on the event page
  • Forms, labels, inputs, select, textarea and button
  • HTML5 input types, datalist and autocomplete

CSS3 topics demonstrated

  1. External stylesheet
  2. Internal stylesheet on the event page
  3. Inline style on the event page
  4. Positioning and dropdown menu
  5. Element dimensions
  6. Box model
  7. Text flow
  8. Media type for printing
  9. Media query for smaller screens
  10. Text shadow and rounded corners
